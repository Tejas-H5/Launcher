# Launcher

I use this program to move around in the file explorer, and launch things.
I'm shocked that this is not how a normal terminal behaves. 

- Up/Down to navigate between folders
- Left/Right to enter/exit folders
    - We remember when you last entered a folder, and the folder view will sort 
        all the folders inside it such that your most recent folder is at the top!
        Why isn't there a `navigate` terminal plugin to let you do this? no clue. lol.
